# Daily reel topic bank – SALES, MARKETING, MOTIVATION (all reels in Hinglish)
Common, universal sales lessons (B2B, field sales, retail, pharma, FMCG). One per reel. Mark used topics by the lesson file that used them (lessons/NNN-*.json). Never invent statistics; use field wisdom framing.

1. "Just checking in" follow-ups -> bring one useful thing (USED 001)
2. Talking more than listening -> ask, then stay silent 3 seconds
3. Pitching features -> sell the customer's result
4. Discounting at the first objection -> ask what's behind the price question
5. "Let me think about it" -> find the real doubt
6. Ending a call without a next step -> always book the next date
7. Opening with "Any requirement, sir?" -> open with their problem
8. Arguing with an objection -> agree, then ask one more question
9. Visiting only friendly customers -> spend time where the growth is
10. Writing reports at month-end -> plan the first week
11. Blaming the territory -> grow one new account a week
12. Selling to the wrong person -> find who really decides
13. No preparation before a call -> 2-minute pre-call check (last visit note)
14. Saying "trust me" -> show proof (a case, a number the customer knows)
15. Over-promising delivery -> under-promise, over-deliver
16. Fear of rejection -> each "no" is data, ask what would change it
17. Asking "Did you like it?" -> ask "What would stop you from starting?"
18. Long WhatsApp messages -> 2 lines + 1 question
19. Ignoring small customers -> small accounts become big ones
20. Not using the customer's name -> remember names and details
21. Closing too late -> ask for the order when buying signals show
22. Complaining about competition -> know your 3 differences by heart
23. Missing the gatekeeper -> respect and remember the receptionist/assistant
24. Generic thank-you -> specific follow-up within 24 hours
25. Selling price instead of value -> show cost of not buying
26. One-way presentations -> ask a question every 60 seconds
27. Promising to "send details" -> send them the same day
28. Giving up after 2 follow-ups -> persistent, useful follow-up
29. Talking about yourself in the opening -> first 10 seconds about them
30. Not asking for referrals -> ask happy customers who else needs this
31. Chasing every lead -> qualify fast: need, budget, timing, decision-maker
32. Hiding bad news -> tell the customer first, with a fix
33. "Our product is the best" -> "Here's what changed for clients like you"
34. Ending the day without a plan -> tomorrow's call list tonight
35. Treating the review meeting as a report -> come with one problem and one plan
36. Overloading the customer with options -> recommend one, explain why
37. Not knowing the customer's goal this month -> ask it every visit
38. Reacting to "too expensive" with defence -> ask "compared to what?"
39. Relying on memory -> note 3 facts after every meeting
40. Waiting for motivation -> start the first call before 10 AM
